# Agent Guidelines

## Commit Messages

Never use the word "add" in commit messages. Use conventional commits format: type: description. The types are feat, fix, docs, chore, refactor, and ci. Keep the first line under 60 characters.

Examples of good commit messages include "feat: new calculator button", "fix: division by zero handling", "docs: update readme screenshots", and "chore: update dependencies".

Avoid these patterns: "add new feature" should use "feat:" instead, "chore: add cla workflow" should use "chore: cla workflow", and "fix: add validation" should use "fix: validation logic".
