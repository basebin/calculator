Calculator

A macOS calculator built with Haskell, GTK4, and haskell-gi

Download

Build

brew install ghc cabal-install gtk4 gobject-introspection
cabal build hello-gtk
cabal run hello-gtk

App Bundle

./scripts/create-bundle.sh
open Calculator.app

Automation

The project uses GitHub Actions for CI/CD. There is a release workflow that builds and creates GitHub releases automatically when a version tag is pushed. A bump version workflow updates the version in the cabal file and creates a git tag which triggers the release. A fix commits workflow runs on every push to main and ensures commit messages do not contain the word "add" by rewriting them if needed.
